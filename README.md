# Scrpt_YA_Orig_Scan

Userscript (Tampermonkey / Violentmonkey) для **Яндекс.Архива**: автоматически сохраняет
**оригинальный скан текущей страницы** одним JPG-файлом в локальную папку загрузок.

Основан на логике расширения [Archive Original Downloader 1.8.8-beta](https://github.com/JPS-Codex/archive-original-downloader),
но сильно упрощён.

## Что изменено относительно расширения

| Было в расширении | В Scrpt_YA_Orig_Scan |
|---|---|
| Яндекс.Архив, ЦГА Москвы, ЦГА Московской области | Только Яндекс.Архив: домены `yandex.ru` и `ya.ru` |
| Один скан, диапазон или всё дело (ZIP / набор JPG) | Только одна страница — текущая |
| Скачивание по кнопке, панель с диапазонами, паузой, повторами | Автоматическое сохранение при открытии страницы скана |
| ZIP, `info.txt`, `errors.txt` | Один отдельный JPG, пересжатый до качества 40% |

## Как работает

1. Вы открываете страницу скана: `https://yandex.ru/archive/catalog/<id>/<номер>` или `https://ya.ru/archive/catalog/<id>/<номер>`.
2. Скрипт сначала дожидается полной загрузки страницы и графики (скан в просмотрщике; ожидание до 45 с, настраивается `GRAPHICS_TIMEOUT_MS`), затем сам запрашивает у Яндекс.Архива оригинал (`/archive/api/image-grant`, `type=original`), пересжимает его в JPG с качеством 40% (размеры в пикселях не меняются) и сохраняет. Если пересжать не удалось, сохраняется оригинал.
3. В правом нижнем углу появляется небольшая плашка со статусом и кнопкой «Скачать скан ещё раз».

Повторное открытие/обновление той же страницы в рамках вкладки второй файл **не** создаёт; для повтора есть кнопка.
Страницы списков (без номера листа в адресе) игнорируются.

Имя файла: `<Архив>_[ЯА]_<фонд>-<опись>-<дело>-<лист 4 цифры>.jpg`,
например `ЦГА_Москвы_[ЯА]_203-780-880-0005.jpg`. Для листа описи — без номера дела.

## Установка

1. Установите менеджер userscript: [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Откройте файл [`Scrpt_YA_Orig_Scan.user.js`](Scrpt_YA_Orig_Scan.user.js) в режиме Raw — менеджер предложит установку.
3. Откройте скан в Яндекс.Архиве.

## Качество JPG

Качество задаётся константой `JPEG_QUALITY` в начале скрипта (`0.4` = 40%). Изменив её, можно получить другой уровень сжатия.

## Папка сохранения

Скрипт сохраняет файл штатной загрузкой браузера — в вашу папку «Загрузки».
Чтобы файлы сразу падали в нужную папку, задайте её в настройках браузера
(`chrome://settings/downloads`) и отключите опцию «Всегда спрашивать, куда сохранять файлы».

## Важно

- Скачивайте только те материалы, к которым у вас есть доступ, и соблюдайте правила Яндекс.Архива.
- Скрипт зависит от текущего устройства сайта; при изменении разметки/API может потребоваться обновление.
